¿Cómo probar el sistema de permisos granulares?

Sigue estos pasos para validar que los permisos afectan directamente al usuario de forma individual:

1

**Configuración Granular:** Dirígete a la nueva pestaña **Permisos**. Selecciona al usuario Carlos Flores (carlos.f@politicas.com) de la lista.

2

**Asignación de Acciones:** Elige la pestaña **Usuarios** en el combobox de la derecha. Activa la acción **Eliminar** para este usuario.

3

**Efecto Inmediato:** Inicia sesión rápido como **Funcionario** (`funcionario`). En la pestaña **Usuarios**, ¡verás que ahora sí tienes habilitado el botón de eliminar!

Roles como Presets

Los roles cargan un conjunto de permisos prearmados, pero el Administrador puede personalizarlos individualmente por cada usuario.
